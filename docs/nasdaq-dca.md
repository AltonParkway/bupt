# 纳指基金动态定投与回测方案

> 本工具用于把定投纪律量化，不构成投资建议。真实交易前应结合基金跟踪误差、费率、税费、汇率、现金流、持仓集中度和个人风险承受能力复核。

## 核心原则

1. **先有长期资产配置，再做定投微调**：纳指基金波动大、行业集中度高，适合作为权益资产中的成长/科技敞口，而不是全部资产。
2. **固定定投是基准**：动态模型必须与固定定投比较，不能只看单独收益。
3. **价值投资约束**：参考格雷厄姆和巴菲特的安全边际思想，用“盈利收益率 - 无风险利率”衡量估值吸引力；安全边际越低，投入越克制。
4. **行业分析约束**：纳指成分偏科技和成长股，单看 PE 容易误判，因此加入收入增长、利润率趋势、行业动量或自定义行业评分。
5. **不预测短期市场**：模型只调整每期投入倍数，保留未投入现金，避免杠杆和一次性押注。

## 量化规则

每月基础定投金额为 `baseContribution`，动态目标投入为：

```text
目标投入 = baseContribution * multiplier
```

`multiplier` 默认限制在 `0.25x ~ 2.5x`，由以下信号加权：

- **价值信号**：`earningsYield - riskFreeYield` 高于安全边际要求时加仓，低于要求时降档。
- **价格逆向信号**：价格低于 12 个月均线时适度加仓，高于均线时控制追高。
- **行业信号**：收入增长、利润率趋势、行业动量或 `industryScore` 越强，投入越积极。
- **利率压力**：无风险利率高于阈值时降低投入强度。
- **波动约束**：近 12 个月波动率过高时降低投入强度。

回测时每月先注入基础预算；若模型目标投入小于基础预算，差额进入现金储备；若目标投入大于基础预算，只能动用已有现金储备，不使用杠杆。

## 使用方法

```bash
npm run nasdaq:dca -- --csv examples/nasdaq-dca-sample.csv --base 1000
```

输出完整 JSON：

```bash
npm run nasdaq:dca -- --csv examples/nasdaq-dca-sample.csv --base 1000 --json
```

## CSV 格式

必需列：

- `date`：月末日期，例如 `2024-12-31`
- `close`：基金净值、收盘价或复权价格

可选列：

- `earningsYield`：盈利收益率，例如 `3.2%` 或 `0.032`
- `riskFreeYield`：无风险利率/十年期国债收益率
- `revenueGrowth`：收入增长率
- `marginTrend`：利润率趋势
- `sectorMomentum`：行业动量
- `industryScore`：自定义行业评分，范围建议为 `-1 ~ 1`

如果缺少可选列，对应信号按中性处理。

## 最佳实践

- 使用低费率、规模充足、跟踪误差较小的纳指基金或 ETF。
- 用至少一个完整牛熊周期的数据做回测，并保留固定定投作为对照组。
- 对国内投资者，另行处理申购费、赎回费、汇率、QDII 限购和场内折溢价。
- 将模型输出视为“投入预算建议”，不要把它当作短线买卖信号。
- 定期复核参数，但避免因最近几个月表现而频繁调参。
